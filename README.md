# Skylanders Generator

App Android nativa en Kotlin para explorar el catálogo local de Skylanders y comprobar la detección de etiquetas NFC.

## Estado inicial

- Catálogo visual de Skylanders Giants con arte incluido en el paquete local.
- Diagnóstico NFC de solo lectura: muestra las tecnologías que Android informa al acercar una etiqueta.
- No se leen ni modifican los bloques o datos de una etiqueta.
- Objetivo de prueba: Samsung Galaxy S25 Ultra, Skylanders Giants para Xbox 360 y Portal of Power.

## Abrir

Abre esta carpeta en Android Studio con JDK 17 y Android SDK 35 instalados; Gradle descargará las dependencias del proyecto.
